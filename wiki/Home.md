# sleight Wiki

**像人一样驱动任何 CDP 浏览器。** Python ≥ 3.11，默认包含 XPath 与 Web 界面，MIT。

这个库分三层，按你要做的事挑入口：

| 层 | 做什么 | 从哪页开始 |
|---|---|---|
| **驱动层** | 导航、查找、拟人点击/输入/拖拽、iframe、截图、网络拦截 | [[浏览器操作API]] · [[拟人化详解]] |
| **LLM 层** | 页面压成模型可读的快照 + 稳定 Ref、正文抽取、五工具网关、MCP server | [[Snapshot与Ref]] · [[MCP与Agent网关]] |
| **运维层** | 部署/运维 CloakBrowser Manager、插件下发、实例池、Web 界面 | [[远程部署]] · [[Web界面教程]] |

## 30 秒

```python
from sleight import connect, Text

with connect("http://127.0.0.1:9222") as s:   # 自己开 tab，退出时关掉
    s.open("https://example.com", wait=Text("Example Domain"))
    print(s.title())
```

## 这个库的取舍

- **不做指纹伪装** —— 那是浏览器内核的事。sleight 负责*驱动*一个反检测内核（见 [[浏览器内核选择]]）。
- **不是 Playwright 替代品** —— 它是驱动层，不做下载/录像/tracing/完整 locator DSL。两者可以一起用。
- **补的是"怎么动"** —— 指纹级反检测已经被解决了，但没有东西解决鼠标怎么移动、键怎么敲。
  即使浏览器侧开了 humanize，外部 CDP 客户端在按下与抬起之间产生的 `mousemove` 是**零个**（实测）。

## 文档约定

- 标 **实测** 的结论都在真实浏览器上验证过，不是推测。
- 「已知限制」写的是真会咬人的东西，不是免责声明——建议先看 [[常见问题]] 再提 issue。
