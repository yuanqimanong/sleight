# 拟人化详解

这页解决：所谓"拟人"到底做了什么、三个档位差在哪、什么时候该关掉。

## 为什么需要它

指纹级反检测是**已经解决**的问题——CloakBrowser 改 Chromium 源码，Camoufox 改 Firefox。
它们解决**浏览器长什么样**。没有东西解决**它怎么动**。

- Playwright / Puppeteer 让鼠标**瞬移**。`mouse.move(steps=N)` 插的是**匀速直线**——
  零抖动、零加速度。这本身就是签名。
- **实测**：即使浏览器侧开了 humanize，外部 CDP 客户端在按下与抬起之间产生的
  `mousemove` 事件是 **零个**。指望浏览器替你补轨迹是空的。

## 具体做了什么

| 维度 | 做法 | 对比典型自动化 |
|---|---|---|
| 路径形状 | 三次贝塞尔，控制点偏向一侧（`bow`）| 直线 |
| 微动作 | WindMouse 风力项（`wind`），**相关**抖动 | 无，或白噪声 |
| 点数 | Fitts 定律：远而小的目标花更久 | 固定 `steps=N` |
| 落点 | 目标框内**截断高斯**（`landing_sigma`）| 正中心 |
| 过冲 | 超阈值距离先冲过头再折回（`overshoot`）| 精确到达 |
| 坐标 | **整数** | 用浮点当"抖动"（本身是特征）|
| 按下前 | 到位后等**反应时间**（`reaction`）| 立即 |
| 双击 | **两次完整**按下抬起，`detail` 依次 1、2 | 一次 `clickCount=2` |
| 打字 | 逐字符事件，间隔按 digraph 分类 | 一次 `insertText` |
| 思考停顿 | 每 `think_every` 个字符插一次停顿，标点后加倍 | 无 |
| 滚动 | 反复的小 `mouseWheel` 增量 | 一次 `scrollTo` |
| 拖拽 | 按钮 mask **全程按住**、滑块级过冲、**松手前停顿** | 瞬移，或一到就松手 |

> **拖拽那条最关键**：*一到就松手*是最可靠的机器特征。真人到位后总有一个几十到几百毫秒的
> 稳定期才松开。

参数不是编的：来自 [WindMouse](https://ben.land/post/2021/04/25/windmouse-human-mouse-movement/)
物理模型、[ghost-cursor](https://github.com/Xetera/ghost-cursor) 的 Fitts 点数预算，
以及已发表的击键动力学测量（左右手交替 digraph 平均 114 ms，同手不同指 131 ms，
同一根手指最慢且方差最大）。

## 三个档位

```python
from sleight import FAST, DEFAULT, CAREFUL
```

真实参数对比（节选，全部字段见 `sleight/core/human/presets.py`）：

| 参数 | FAST | DEFAULT | CAREFUL | 含义 |
|---|---|---|---|---|
| `wind` | 1.5 | 3.0 | 3.5 | 抖动强度 |
| `bow` | 0.1 | 0.18 | 0.26 | 路径弯曲度 |
| `overshoot` | 0.3 | 1.0 | 1.4 | 过冲幅度 |
| `overshoot_threshold` | 500 | 500 | 320 | 超过多远才过冲（px）|
| `step_delay` | .006–.014 | .008–.020 | .010–.024 | 每个轨迹点之间（秒）|
| `reaction` | .06–.18 | .06–.18 | .12–.32 | 到位后按下前（秒）|
| `key_dwell` | .04–.075 | .06–.12 | .07–.15 | 按键按住时长（秒）|
| `typing_scale` | 0.7 | 1.0 | 1.35 | 打字整体速度倍率 |
| `think_every` | 14–26 | 8–15 | 5–11 | 每几个字符插一次思考停顿 |
| `think_pause` | .1–.3 | .2–.6 | .3–.9 | 思考停顿时长（秒）|
| `drag_settle` | .05–.14 | .08–.24 | .15–.45 | **拖拽松手前的停顿**（秒）|
| `scroll_delay` | .018–.045 | .03–.08 | .05–.13 | 滚动步之间（秒）|

共有且不随档位变的：`gravity=9.0`、`max_points=220`、`landing_sigma=0.25`、
`edge_inset=3`、`min_duration=0.05`、`max_duration=2.5`、`punctuation_think_bonus=2.0`。

**怎么选**：
- `FAST` —— 内部系统、自己的测试环境、不设防的页面。
- `DEFAULT` —— 日常默认。
- `CAREFUL` —— 验证码滑块、风控严的表单提交、账号敏感操作。

## 三态开关

```python
# Session 级默认
with inst.session(human=True) as s: ...          # 全部动作用 DEFAULT
with inst.session(human=CAREFUL) as s: ...       # 全部动作用 CAREFUL

# 单句覆盖
s.click("#login")                 # None → 继承 Session 默认
s.click("#submit", human=False)   # 直通，最快（这一下要的是速度）
s.drag("#knob", by=(212, 0), human=CAREFUL)      # 这一下要最像人
```

| 值 | 语义 |
|---|---|
| `None` | 继承 Session 默认（**单句参数的默认值**）|
| `False` | 直通——不生成轨迹，0 条中间 `mousemove` |
| `True` | 用 `DEFAULT` 预设 |
| `HumanProfile` | 用指定档位 |

`resolve_profile()` 的规则：单句参数优先于 Session 默认；传了 bool/HumanProfile/None
之外的东西抛 `TypeError`。

## 可复现

传一个固定 seed 的 `random.Random`，整段交互可复现（调试轨迹问题时有用）：

```python
from random import Random
with inst.session(human=True, rng=Random(42)) as s: ...
```

## 单独用 human 层（配 Playwright）

`sleight.core.human` 是 [sans-io](https://sans-io.readthedocs.io/) 的——只产出
`(method, params, sleep_after)` 三元组，**从不碰 socket**。所以可以拿它驱动
Playwright 的 `CDPSession`，只借轨迹不要其余部分。

## 注意

- **裸坐标不做命中校验**。给 `Point`/`Box` 时轨迹照走，但不校验落点是否被遮挡。
  要安全就给选择器或 Ref。
- **拟人不能替代出口 IP**。风控经常先看 IP 信誉，动作再像也过不了——见
  [[反检测实战与限制]]。
