# 安装

这页解决：装什么、装哪些可选件、怎么装浏览器内核、怎么验证装好了。

## 装库

```bash
pip install sleight
```

Python ≥ 3.11。默认安装包含 `websocket-client`、`lxml`、`fastapi` 和 `uvicorn`，
可以直接使用 `session.parse(xpath=True)`、`StaticElement.xpath()` 和 `sleight ui`。

## 服务与数据库

只保留 `pip install sleight`，XPath、Web、MCP、SQLite 和 PostgreSQL 驱动均默认安装。
`sleight ui` 首次生成管理员 token，之后在 Web 签发各用户的访问 token。
不再提供 `[redis]` extra，也不需要 Redis 服务。
部署时只有 Python 服务；Node 仅用于 GitHub 构建前端页面。

默认使用 `$SLEIGHT_HOME/control.db`。设置 `SLEIGHT_DATABASE_URL` 可切到 PostgreSQL。
数据库切换前停止服务、排空会话，见 [[分布式与实例池]] 及仓库 `docs/0.6部署与验收.md`。

> **注意**：默认 `parse()` 仍使用内建 CSS 子集；要用 XPath 的轴、位置谓词、
> `contains()` 等语法，调用 `parse(xpath=True)`，不需要额外安装。见 [[数据提取]]。

## 装完有两个命令

```bash
sleight --help        # 运维 CLI（部署、插件、实例、内核、界面）
sleight-mcp           # MCP server（stdio），给 Claude Desktop 之类的 MCP host 用
```

## 装浏览器内核

sleight 自己不带浏览器。你有三个选择：

### 选择 1：用系统已有的 Chrome / Chromium（最简单）

不用装任何东西，直接指路径或让它在 `PATH` 上找：

```python
from sleight import launch
with launch("chromium") as s:          # 或 "google-chrome"，或绝对路径
    s.open("https://example.com")
```

### 选择 2：装一个反检测内核（推荐做真实任务时用）

像 `playwright install` 那样一条命令：

```bash
sleight browser ls                              # 看有哪些可装的、已装了什么
sleight browser install fingerprint-chromium    # 下载 + 解包，幂等
sleight browser path                            # 打印可执行文件路径
sleight browser rm fingerprint-chromium         # 删掉
```

装到启动目录的 `data/browsers/<内核>/<版本>/`（`$SLEIGHT_HOME` 可改），并写一份
`manifest.json` 记录下载地址、SHA-256、可执行文件路径。

装完直接用**内核名**就行，不必写绝对路径：

```python
with launch("fingerprint-chromium", fingerprint=42) as s: ...
```

> **供应链提醒（诚实说明）**：这是从第三方 GitHub Release 下载并运行一个浏览器二进制。
> 上游没有发布签名校验和，所以 `manifest.json` 里的 SHA-256 **只能**证明"下载之后没被改过"，
> **不能**证明它由对应源码构建。介意的话就别走这条路，自己拿 binary 传绝对路径。

体积参考：Linux tar.xz 约 141 MB，Windows zip 约 190 MB，macOS dmg 约 140 MB。**仅 x86_64**。

### 选择 3：CloakBrowser（闭源，本地自用免费）

自己从官方渠道下载后传绝对路径。详见 [[浏览器内核选择]]。

## 验证

```bash
python -c "import sleight; print(sleight.__version__)"
sleight browser ls
```

跑通一个真实页面：

```python
from sleight import launch
with launch("chromium", no_sandbox=True) as s:   # Linux 上以 root/容器跑要 no_sandbox
    s.open("https://example.com")
    print(s.title())        # Example Domain
```

打印出标题就说明整条链路（起进程 → CDP → 导航 → 读取）通了。

## 数据存在哪

| 路径 | 内容 |
|---|---|
| `data/control.db` | 配置、身份、运行管理和审计（CLI 与 Web 共用的 SQLite）|
| `data/browsers/` | 装下来的浏览器内核 |
| `data/native/` | 原生浏览器实例及登录态 |
| `data/secret.key` | 配置加密密钥，备份时与数据库一起保存 |
| `data/hosts.toml` | 旧版主机清单（会被自动导入 SQLite）|

`data/` 相对于启动工作目录。`$SLEIGHT_HOME` 环境变量可以整体改这个目录（测试隔离也靠它）。

卸载库使用 `pip uninstall sleight`；数据目录独立保留。
