# 指纹与人格

这页解决：怎么让一个实例的身份**自洽且稳定**。

## 两个层次

| 层次 | 谁提供 | 怎么配 |
|---|---|---|
| **本机内核的指纹** | fingerprint-chromium / CloakBrowser | `launch(..., fingerprint=<seed>)` |
| **远程 Manager 的 profile** | CloakBrowser Manager | `ProfileSpec` / `sleight profiles create` |

## 种子决定一切

```python
launch("fingerprint-chromium", fingerprint=42)
```

一个 32 位整数派生出一整套一致身份：UA / UA-CH、平台、Canvas、WebGL、音频、字体、
时区、硬件并发数、设备内存。

**实测**（本项目在真 binary 上验证）：

| | seed=42 | seed=777 |
|---|---|---|
| GPU | `Intel Iris Xe` | `Intel UHD 620` |
| 硬件并发 | 14 | 28 |
| 跨启动 | **完全一致** | **完全一致** |

要点：
- **同 seed = 同指纹**，跨进程重启也一样 → 适合长期账号。
- **换 seed = 换身份**。
- 标准 Chromium **不认** `--fingerprint`，传了没用。

配上持久 profile 才完整：

```python
launch("fingerprint-chromium", fingerprint=42, profile_dir="/data/persona-a")
```
身份（指纹）+ 状态（cookie、登录态）都稳定。

## 远程 profile：平台 × 地区

建实例时身份由**两个正交维度**决定：

```bash
sleight profiles create Win-US-02 --preset windows --region us_east
```
```python
from sleight.providers import ProfileSpec, Region

spec = ProfileSpec.windows("Win-US-02", Region.US_EAST)
spec = ProfileSpec.macos("Mac-HK-01", Region.HK)
spec = ProfileSpec.linux("Lnx-DE-03", Region.DE)
```

### 平台工厂（3 个）

| 工厂 | 锁定 |
|---|---|
| `ProfileSpec.windows(name, region, **kw)` | Windows 平台串 + 对应 GPU |
| `ProfileSpec.macos(name, region, **kw)` | macOS 平台串 + Apple GPU |
| `ProfileSpec.linux(name, region, **kw)` | Linux 平台串 + Mesa GPU |

### 地区枚举（8 个）

`us_east` `us_west` `uk` `de` `hk` `sg` `jp` `cn` —— 每个锁定**时区 + 语言**。

CLI 用 `--region us_east`，Web 界面下拉框，Python 用 `Region.US_EAST` —— **三处同一份定义**。

## 为什么要串锁

这些字段**不能随便组合**。反例：

```
platform = "windows"  +  GPU = "Apple M2 Metal"      ← 一眼假
platform = "macos"    +  时区 = "Asia/Shanghai" + 语言 "en-US" + 代理出口在德国   ← 三处互相矛盾
```

真实设备上，平台、GPU、时区、语言、字体是**互相约束**的。工厂 + 地区枚举的意义就是
**只让你组合出真实存在的搭配**，而不是给你 20 个自由输入框然后自己去踩雷。

**还要自己保证的**：代理出口的地理位置要和 `region` 对得上。给一个 `us_east` 的 profile
配德国代理，时区/语言/IP 三者矛盾，比不配代理还显眼。

## 其它可调项

```bash
sleight profiles create NAME --preset windows --region us_east \
    --proxy http://user:pass@host:8080 \
    --screen 1920x1080 \
    --tags us,prod \
    --geoip \                 # 按出口 IP 自动定位
    --headless \
    --seed 42 \               # 指纹种子
    --notes "主账号"
```

`--tags` 之后可以用来筛实例：`pool.lease(where=lambda i: "us" in i.tags)`。

> 注：Web 界面的新建表单目前**没有** `--seed` 和 `--notes` 的输入框（后端 API 支持），
> 要用这两个得走 CLI。见 [[Web界面教程]]。

## 一个反模式

**每次启动随机换指纹**。有些内核（如 ungoogled-chromium 的 Bromite canvas 噪声）是
**每次会话随机**的——在"同一账号 = 同一台设备"的场景里这**帮倒忙**：
同一个账号今天是 A 设备明天是 B 设备，比固定一个假身份更可疑。

长期账号：**固定 seed + 固定 profile_dir**。
