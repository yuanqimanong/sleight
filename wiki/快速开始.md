# 快速开始

这页解决：三条最短可跑路径，以及一个端到端的完整例子。

## 三条路径，挑一条

### ① 连一个已经在跑的浏览器

先手动起一个带调试端口的浏览器：

```bash
chromium --headless=new --remote-debugging-port=9222 --user-data-dir=/tmp/prof
```
```python
from sleight import connect, Text

with connect("http://127.0.0.1:9222") as s:
    s.open("https://example.com", wait=Text("Example Domain"))
    print(s.title())
```
`connect()` 会**自己开一个 tab**（不接管你正在看的页面），退出时关掉它。

### ② 让 sleight 起本机浏览器（最省事）

```python
from sleight import launch

with launch("chromium", no_sandbox=True) as s:      # Linux root/容器要 no_sandbox
    s.open("https://example.com")
    print(s.title())
# 退出时：浏览器进程停掉、临时 profile 删干净
```

换成反检测内核只改一个词（先 `sleight browser install fingerprint-chromium`）：

```python
with launch("fingerprint-chromium", fingerprint=42) as s: ...
```

### ③ 连远程的 CloakBrowser Manager

```python
from sleight.providers import CloakBrowserManager

mgr = CloakBrowserManager("http://127.0.0.1:19000", token="…")

with mgr.lease() as inst:                 # 排他租用，退出即释放
    with inst.session(human=True) as s:   # 每个动作都走拟人轨迹
        s.open("https://example.com")
```

## 5 分钟完整例子

起浏览器 → 开页 → 拍快照 → 按 Ref 点击 → 抽正文：

```python
from sleight import launch
from sleight.core.types import Load

with launch("chromium", no_sandbox=True) as s:
    s.open("https://text.npr.org/", wait=Load())

    # 1) 把页面压成 LLM 能读的树，可交互元素带 [ref]
    snap = s.snapshot()
    print(snap.text()[:400])

    # 2) 按文字找到第一条新闻链接的 ref 并点它
    def find(node, kw):
        if node.ref and kw.lower() in node.name.lower():
            return node.ref
        for c in node.children:
            if (r := find(c, kw)):
                return r
    ref = find(snap.root, "")           # 或换成具体标题关键词
    if ref:
        s.click(snap.ref(ref))          # 真实 isTrusted 事件，走拟人轨迹
        s.wait(Load(), timeout=30)

    # 3) 抽正文和常用字段
    doc = s.extract_document()
    print(doc.title)
    print(doc.byline, doc.char_count, "quality:", doc.quality)
    print(doc.text[:300])
```

## 批量只读用静态树

要读很多元素时，别为每个元素付一次 CDP 往返：

```python
dom = s.parse()                                        # 一次抓取，之后纯内存
names  = [e.text for e in dom.query_all("tr.row td.name")]
prices = [e.text for e in dom.query_all("tr.row td.price")]
```
50 行表格实测约快 **18 倍**。XPath 已包含在默认安装中，调用
`s.parse(xpath=True).xpath("//tr[3]/td")`。

## 让 LLM 直接驱动

```bash
SLEIGHT_BROWSER=fingerprint-chromium SLEIGHT_FINGERPRINT=42 sleight-mcp
```
在 Claude Desktop 之类的 MCP host 里配成一条 stdio 命令即可，详见 [[MCP与Agent网关]]。

## 常见起步问题

| 症状 | 原因 |
|---|---|
| `browser binary 'xxx' not found on PATH` | 传绝对路径，或先 `sleight browser install` |
| Linux 上浏览器起不来 | 加 `no_sandbox=True`（root 或容器里必须）|
| 点击抛 `ElementError: is covered` | 元素被遮挡了（cookie 横幅/固定头部），错误消息里有挡住它的元素 |
| `wait` 秒回但页面是空的 | 目标会重定向，改等页面自己的东西：`wait=Selector("#x")` |
| 连不上我日常开着的 Chrome | Chrome 136+ 对默认用户目录禁用了调试端口，需用独立 `--user-data-dir` |
