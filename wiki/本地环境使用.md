# 本地环境使用

这页解决：在自己机器上起浏览器跑任务，分系统的注意事项。

## 两个入口

### `launch()` —— 一个 Session，最省事

```python
from sleight import launch

with launch("fingerprint-chromium", fingerprint=42) as s:
    s.open("https://example.com")
# 退出时：进程停掉、临时 profile 删干净
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `binary` | — | 内核名（已装的）、`PATH` 上的名字，或绝对路径 |
| `fingerprint` | `None` | 指纹种子。标准 Chromium **不认**这个参数，别传 |
| `headless` | `True` | 要有头 UI 传 `False` |
| `no_sandbox` | `False` | Linux 上以 root 或容器里跑**通常必须** `True` |
| `profile_dir` | `None` | 持久 profile 目录；`None` 用临时目录并在退出时删除 |
| `args` | `()` | 追加启动参数，如 `["--proxy-server=socks5://127.0.0.1:9050"]` |

`**kw` 透传 `Session`：`human`、`rng`、`track_network`、`track_runtime`（后两个见
[[浏览器操作API]] 的「事件量开关」）。

### `LocalLauncher` —— 要池/租约/复用

```python
from sleight.providers import LocalLauncher

with LocalLauncher("fingerprint-chromium", fingerprint=42,
                   profile_dir="/data/persona-a", no_sandbox=True) as browser:
    with browser.lease() as inst, inst.session(human=True) as s:
        s.open("https://example.com")
    # 还可以再租、开 context 换出口等
```

它是一个 Provider（单实例，id 固定 `"default"`），所以 `Pool` / `lease` / `context()`
那套都能用。方法：`ensure_ready()` `endpoint()` `status()` `recover()` `close()`。

## 分系统

### Linux

```python
launch("fingerprint-chromium", fingerprint=42, no_sandbox=True)
```
- **root 或容器里必须 `no_sandbox=True`**，否则浏览器起不来。
- 要有头就配 Xvfb / Xvnc：`xvfb-run -a python task.py`。
- fingerprint-chromium 的 **WebGL GPU 元数据伪装只在 Linux 全生效**。

### Windows

```python
launch(r"C:\Program Files\fingerprint-chromium\chrome.exe", fingerprint=42)
# 或装过之后直接：
launch("fingerprint-chromium", fingerprint=42)
```
不需要 `no_sandbox`。装内核后 `sleight browser path` 能打印出真实路径。

### macOS

```python
launch("/Applications/Chromium.app/Contents/MacOS/Chromium")
```
- **要指到 `.app` 里的真实可执行文件**，不能直接给 `.app` 目录。
- `sleight browser install` 会自动挂载 dmg、拷出 `.app` 并找到里面的可执行文件。
- ⚠️ **Apple Silicon（ARM）**：fingerprint-chromium **只有 x86_64 构建**，原生跑不了。
  用系统 Chrome，或走 Rosetta（未测），或改用远程环境。

## 持久 profile vs 临时

| | 临时（`profile_dir=None`）| 持久（给路径）|
|---|---|---|
| 登录态 | 每次都没有 | **保留** |
| cookie / localStorage | 每次干净 | 保留 |
| 退出时 | **自动删除** | 不删 |
| 适合 | 一次性抓取、测试 | 长期账号任务 |

长期账号任务建议：**固定 `fingerprint` seed + 固定 `profile_dir`**——身份和状态都稳定。

```python
launch("fingerprint-chromium", fingerprint=42, profile_dir="/data/persona-a")
```

## 崩溃恢复

```python
prov = LocalLauncher("fingerprint-chromium", fingerprint=42, profile_dir="/data/a")
prov.ensure_ready("default")
...
prov.recover("default")      # 进程崩了：重启，复用同一个 profile 和种子
```
**只恢复进程，不重放业务动作**——重放可能意味着重复提交。

## 进程清理

三重保险，通常不用操心：
1. `with` 退出 → `close()`
2. 显式 `close()` → 停进程 + 删临时 profile（持久的不删）
3. 忘了关 → `atexit` 兜底

端口默认自动挑空闲的，**只绑 loopback**（`127.0.0.1`），不会暴露到网络上。

## 常见问题

| 症状 | 原因 |
|---|---|
| `browser binary 'x' not found on PATH` | 传绝对路径，或先 `sleight browser install x` |
| `browser kernel 'x' is not installed` | 是已知内核名但没装，按提示跑 install |
| `browser exited early (rc=…)` | 参数不对；Linux 上多半缺 `no_sandbox=True` |
| `did not expose CDP within 30s` | 起太慢或被杀；调大 `start_timeout`，或看是不是内存不够 |
