- 将 Sleight 实例 ID 映射到 Manager profile，优先进入对应实例；无法直达时打开 Manager，并提示实例名称和 profile ID。
- 沿用用户权限和 Manager 鉴权，不在地址、日志或页面中暴露 Manager token。
- 启动中、运行中、已停止及已回收分别显示明确状态。临时实例回收后保留结束信息，不提供失效的查看链接。
