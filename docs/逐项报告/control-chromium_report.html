关闭释放与内存趋势核查

100次正式网页与5个独立实例已执行。关闭后Browser PSS均为0，支持进程和临时profile清空；本项容器已停止。

逐页关闭后的cgroup内存首尾变化约109.5 MiB；它还包含显示服务、仍在退出的worker、文件缓存等，不是浏览器独占内存。

新增memory.stat只覆盖采样实际存在的时段；缺失的历史匿名内存/文件缓存不回填。不同网页和5个短周期不能证明长期泄漏或无泄漏。

Browser PSS为观测最大值，不是连续峰值；未采到的SDK运行期内存保持未知。每实例仅1次指纹样本，不评价同实例重复稳定性。

HTTP200不等于反检测验收通过。失败、未知和授权受限保留；无同期完整nodriver基准，不强排精确名次。

本批次按原顺序、每组最多2个测试容器运行，资源不足时降至单容器；未恢复定时任务。
